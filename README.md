# Condo Director's Financial Assistant

*A Claude Code skill that synthesizes your corporation's financial documents into a board-ready report.*

## Why I made this

As condo board directors, every month we receive a package of financial documents — balance sheets, variance reports, bank statements, meeting minutes — and we'd like to walk into a board meeting with a clear picture of where things stand. In practice, synthesizing all of that into a coherent view takes more time than most board members have, and the important signals are easy to miss: a line item quietly running 40% over budget, a contractor quote buried in the manager's report that will materially affect the reserve fund.

I built this Claude Code skill to do that synthesis for me. I run it inside the directory where I keep all my condo board materials, ask it to run the report, and get back a structured analysis with source citations, priority flags, and a forward-looking section that surfaces things in the meeting minutes that haven't hit the financial statements yet. It saves a timestamped report each run and works incrementally — subsequent runs read only what's new and update only what changed.

It's built for my Ontario corporation, but the skill is jurisdiction-aware and designed to be extended. An Ontario reference file is included; for other jurisdictions it prompts you with instructions to generate one.

## Quickstart

### 1. Install Claude Code

If you're here, you probably know what [Claude Code](https://claude.ai/code) is. If not — follow the link, install it, and make sure you can run it from your terminal. This skill might work with other coding agents, but I haven't tested it outside Claude Code.

### 2. Install the skill

Skills live in `~/.claude/skills/`. Clone this repository there:

```bash
git clone https://github.com/your-org/condo-corp-financial-analyst ~/.claude/skills/condo-corp-financial-analyst
```

Claude Code picks up skills automatically — no further configuration needed.

### 3. Organize your documents

Create a directory for your corporation and organize your documents into it. The layout below is what I use and what the skill expects; other structures may work, but this is the one it was developed against.

```
YourCorporation/
├── Board Meetings/          # monthly board packages: minutes, agendas,
│   ├── 2025-10/             # manager's reports, financial statements,
│   │   ├── minutes.pdf      # variance reports, bank statements
│   │   ├── managers-report.pdf
│   │   ├── financials.pdf
│   │   └── variance.pdf
│   └── 2025-11/
│       └── ...
├── Documents/               # semi-permanent reference documents:
│   ├── declaration.pdf      # declaration, by-laws, rules, reserve fund
│   ├── by-laws.pdf          # study, insurance certificate, budget
│   ├── rules.pdf
│   ├── reserve-fund-study.pdf
│   └── budget-2025-26.pdf
└── Reports/                 # created automatically by the skill
```

### 4. Run it

Open Claude Code in your corporation's directory and ask:

> "Run the financial report."

Or ask focused questions:

> "How is the reserve fund tracking against the study projections?"  
> "Show me the arrears trend."  
> "True up the report — what's changed since last month?"

The skill saves a timestamped report to `Reports/` and prints a summary inline.

---

## What the report covers

- **Operating fund** — revenue, expenses, net income vs. YTD budget
- **Reserve fund** — total assets, investments, capital expenditures, drawdown
- **Reserve fund study context** — projected vs. actual, minimum balance trajectory
- **Notable variances** — over- and under-budget line items, source-cited
- **Summary scorecard** — key metrics across periods
- **Priority flags** — high / medium / positive items for the board
- **Forward-looking context** — capital projects, contractor quotes, and committed costs pulled from meeting minutes that haven't appeared in the financials yet
